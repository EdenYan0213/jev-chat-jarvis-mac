## 正文

先说这次更新要解决的问题。

微信 macOS 更新到 4.1 之后，这个工具最要紧的一个动作——点「填入」，把候选回复写进微信输入框——在部分环境里失灵了。

原因不复杂：原来的路依赖系统向工具暴露「输入框控件」，新版微信在部分环境下不再提供它。路没了，活还得干，所以 v0.4.0 换了一条路。

新的走法是「视觉兼容路径」：点「填入」时先复核窗口、输入区和会话标题，确认还是刚才那个聊天；然后激活微信、点一下输入区、用键盘事件把文字送进去；最后 OCR 读回确认，对得上才算成功。

红线一条没动：不按发送键（发不发、发什么，永远你自己按），不用剪贴板，也不模拟 Cmd+V——剪贴板那条路看着省事，实际会抢前台、会覆盖你剪贴板里的东西，失败了还可能把文字贴进别的应用。输入框里已经有草稿时，它会停下来提示你改用「复制」手动插入；窗口、焦点或会话一变就中止；失败不自动重试。「填错地方」比「填不上」麻烦得多，所以宁可停。

**如果你第一次见到它**

这是一个贴在微信窗口旁边的 macOS 悬浮窗。有新消息时它读出最新那条，给你三样东西：

- **这句话的意图**：派活 / 催进度 / 问进度 / 批评 / 要解释 / 闲聊 / 约会议 / 夸奖，8 类
- **风险分级 0–9**，带颜色，配一句行动建议
- **回复候选，按「话术」分组**：内置 10 种话术（高情商话术、贴吧老哥、拒绝加班、卑微乙方、稳如老狗、已读乱回、鱼塘主、职场黑话、阴阳怪气、理科直男），每种写 2 条——同一种语气、一稳一放，组内按合适度排好序。面板下方能自己挑同时开哪三种。

看中哪条，点「复制」或「填入」。就这些。

**一些实测口径**（M1 Pro，README 里也是这么标的）

- 8 类意图在 22 条中文回归里零样本 86.4%（**无上下文口径**，即只看单条消息）
- 消息进来到出意图约 1.5 秒，出候选约 1.5–2 秒——判断和生成同时起跑，所以你先看到意图和风险，候选随后到

候选不是生成完就端上来的：写完会先丢回本地模型排一遍序。比如一句「这做的什么玩意」（批评），生成的候选里混着一条「哈哈，老板，我这就改！」，本地排序把它压到第 3，把「对不起，我马上改！」排到第 1——这就是排序必须留在本地、而且必须由不讲情面的判断层来做。

**边界再说一遍**

不注入微信、不 hook、不解密本地数据库、不自动发送任何消息。原理是截屏 + OCR（只扫聊天区）+ 本地小模型判断，对微信来说就是「屏幕上有个人在看」。判断层全程在本地、不出网。

只有点「填入」这一个「写」的动作会碰到微信，而且不发送。需要说明的是：候选回复由第三方 LLM 端点生成，消息正文会发到那里；不想出网可以把生成层换成自己的 Ollama，代价是慢一点。

**v0.4.0 还顺手做了**

- **模型设置可视化**：点悬浮窗右上角的齿轮，或菜单栏 J → 模型设置…，三组密钥（Jev / OpenAI 兼容 / Anthropic 兼容）的地址和模型都能在窗口里改，还能点「获取模型列表」从服务端拉。保存后退出重开生效，不用再手改配置文件。
- **面板视觉层优化**：排版更稳，长候选自动增高、不截断。
- 启动器安装 uv 失败时的提示更具体（网络、证书、磁盘、安装器分别提示），排障不用猜。

**怎么装**

macOS 13+。在 Releases 页下载 zip，解压把 jev-jarvis.app 拖进「应用程序」，第一次右键 → 打开（没做 Apple 公证，只需这一次）。

如果弹的是「已损坏，无法打开」（浏览器下载的 zip 常见，右键也绕不过），别删，在终端跑一句清掉隔离属性：

`sudo xattr -r -d com.apple.quarantine /Applications/jev-jarvis.app`

首次启动按提示给「屏幕录制」权限，退出重开；「填入」再给「辅助功能」。判断层默认跑本地模型，首次要下载，之后离线可用；不想下载就配一个云端 key。
